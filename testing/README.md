# Тестирование продукта другой команды

Материалы второй части практической работы: тестирование приложения Student Task Manager методом «чёрного ящика».

| Файл | Что это |
|---|---|
| `stm_autotest.py` | Сценарий: запускает приложение, работает с его окном как пользователь и сравнивает результат с требованиями ТЗ |
| `results/protocol.txt` | Протокол прогона: шаги, ожидаемый и фактический результат, статус каждого из 46 тестов |
| `results/results.json` | Те же результаты в машинном виде — из них собирается таблица тест-кейсов в отчёте |
| `results/screens/` | Снимки окна приложения, сделанные во время прогона |

Запуск (Windows, Python 3.11+; для снимков нужен пакет Pillow):

```powershell
pip install pillow
python testingstm_autotest.py <папка с student_task_manager.py> testingesults
```

Каждый тест работает со своей копией продукта и своим файлом данных, поэтому исходная папка приложения не изменяется. Сам тестируемый продукт в репозиторий не входит: он принадлежит другой команде.

Итог прогона от 19.09.2026: 46 тестов, 27 пройдено, 19 не пройдено, найдено 11 дефектов. Разбор — в разделе 4 [отчёта](../reports/).
