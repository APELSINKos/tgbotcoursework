> Не просто «+12°C», а «🌧 Через 40 минут дождь — возьми зонт».

Бот, который по утрам сам пишет первым: какая погода, что запланировано на день и сколько дней держится серия твоей привычки. Погода, напоминания, заметки, привычки и курсы валют — в одном чате.

Проект выполнен в рамках практических работ по дисциплине **«Тестирование, верификация и валидация программного обеспечения»** (РТУ МИРЭА).

## ✨ Что умеет бот

| Раздел | Что делает |
|---|---|
| 🌤 **Погода** | Текущая погода в твоём городе и «умные» советы: зонт, одежда, велосипед |
| 📅 **Мой день** | Одно сообщение со всем важным: дата, погода, напоминания, привычки, заметки |
| ⏰ **Напоминания** | Напишет в нужное время: `18:30`, `25.09 18:30` или `25.09.2027 18:30` |
| 📝 **Заметки** | Короткие записи, чтобы ничего не забыть |
| 🎯 **Привычки** | Отметки ✅ / ❌ каждый день, статистика и серии |
| 💱 **Курс валют** | Доллар и евро по курсу ЦБ РФ и конвертер в обе стороны |
| ⚙️ **Настройки** | Город и время утренней сводки |

### Утренняя сводка

Главная фишка — бот пишет сам, без запроса:

```
☀️ Доброе утро!

🌡 Москва: +11…+17°C
☔ Дождь ожидается после 18:00 — зонт сегодня пригодится

📌 Сегодня:
• 12:30 — встреча
• 19:00 — тренировка

🔥 Серия привычки «спорт»: 6 дней
```

### Трекер привычек

```
1. Спорт — 12/17 дней 🔥
    Текущая серия — 5 дней
```

## 🚀 Быстрый старт

Нужен Python 3.10 или новее.

**Windows (PowerShell):**

```powershell
git clone <адрес репозитория>
cd <папка репозитория>
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

**Linux / macOS:**

```bash
git clone <адрес репозитория>
cd <папка репозитория>
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Токен бота читается из переменной `BOT_TOKEN`. Когда в консоли появится `Bot is running`, открой бота в Telegram и отправь `/start`.

## 🧩 Как устроен проект

```
├── bot.py          точка входа: /start, главное меню, запуск
├── loader.py       создаёт объект бота
├── config.py       настройки и лимиты, чтение токена из .env
├── database.py     вся работа с базой SQLite
├── keyboards.py    кнопки
├── weather.py      погода и «умные» советы
├── currency.py     курсы ЦБ РФ и конвертер
├── notes.py        заметки
├── reminders.py    напоминания
├── habits.py       трекер привычек
├── my_day.py       «Мой день» и текст утренней сводки
├── settings.py     город и время сводки
├── scheduler.py    фоновый поток: напоминания и утренняя сводка
├── deploy/         служба systemd для запуска на сервере
├── docs/           техническое задание, руководство, архитектура, развёртывание
└── reports/        отчёты по практическим работам
```

Каждый раздел меню — отдельный файл. Данные хранятся в одном файле `bot.db`, который создаётся при первом запуске.
